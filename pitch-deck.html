THE MISSING METRIC

Recovery Debt

Recovery Debt = OCH Score - Biological Score (Sleep + HRV)
STABLE < 15 - recovering well WARNING 15-30 - recovery declining CRITICAL > 30 - biological debt

We model recovery as a time-series signal, not just a static snapshot. The debt accumulates across incidents and decays based on actual sleep and HRV recovery patterns.

This metric doesn't exist anywhere else.

PRIVACY & ETHICS

Raw biological data NEVER leaves the device.

ON DEVICE (Private)

  • Heart rate data
  • Sleep stages
  • HRV values
  • Fragmentation index

SHARED (Opt-in)

  • Readiness score (0-100)
  • Recovery delta
  • "Available" / "Recovery Mode"
  • Handoff request
  • This system protects engineers, not evaluates performance. Cannot be used for reviews.
  • No medical claims - this is decision support, not diagnosis
  • Engineer controls sharing - one tap to revoke

What Could Go Wrong

False positives

System flags recovery debt when engineer is fine

> Mitigation: signal is advisory, not authoritative. Human approval required for all actions.

Signal misread

Wearable data misinterprets recovery state

> Mitigation: calibrated per user over time. DREAMT baselines as starting point, not ground truth.
